# 九九乘法乐园 🎡

给一年级小朋友的乘法学习小游戏。理解优先、鼓励优先、玩着玩着就背会了。

## 运行

无需构建，纯前端。任选其一：

```bash
# 方式一：本地服务器（推荐，手机/平板同一 Wi-Fi 也能访问）
python3 -m http.server 8899
# 然后浏览器打开 http://127.0.0.1:8899

# 方式二：直接双击 index.html 也能玩
```

## 玩法

| 模块 | 内容 |
|------|------|
| ▶ 开始游戏 | 从最新进度继续闯关 |
| ⭐ 关卡挑战 | 9 大关 = 1~9 的乘法，通关解锁下一关，1~3 星评价 |
| 🎁 学习模式 | 乘法的意义（分组可视化）/ 口诀表点读 / 翻卡片 |
| 🏆 学习报告 | 星星、金币、正确率、徽章墙、错题本 |

## 教学设计（第一性原理）

- **理解先于记忆**：答错/提示都会展示「a × b 就是 a 个 b 相加」的分组解释；学习模式有可视化分组动画
- **螺旋复习**：第 3 关起混入约 25% 已学内容；高关卡混入交换律题型
- **建立信心**：每关第一题固定为简单题（×1 或 ×2）
- **低压力计时**：第 1 关不限时，2~4 关 25 秒，逐关收紧到 15 秒；切后台自动暂停
- **错误是学习机会**：答错展示正确答案+加法展开，记入错题本；改正后错题自动移除
- **即时激励**：答对星星爆炸/连击彩虹/通关烟花彩带 + 合成音效 + 语音鼓励

## 道具

💡 提示（消除 2 个错误选项 + 加法提示）· 🍃 跳过（不扣爱心）· ⏰ 加时（+10 秒）

## 技术

- 原生 HTML/CSS/JS，零依赖零构建；ZCOOL KuaiLe 俏皮字体（加载失败自动降级系统字体）
- 音效全部 Web Audio 实时合成，无音频文件；题目朗读用 Web Speech API（可关）
- 进度存 localStorage（隐私模式自动降级内存；类型污染防御；多标签页防互踩）
- 图片素材带 emoji 降级，素材缺失也能玩
- 响应式：手机（≥320px）/ iPad / PC，触摸目标 ≥56px，尊重系统减弱动画偏好

## 已通过的对抗性测试

- 题库：9 关 × 300 轮生成，选项必 4 个、唯一、含正确答案、无重复题、首题必简单
- 存储：损坏 JSON 恢复 / 旧版本合并 / 类型污染攻击 / 隐私模式降级 / 多标签页并发写
- 真机浏览器实测：答题、超时扣心、三道具、失败&通关结算、错题本、徽章、三端视口
